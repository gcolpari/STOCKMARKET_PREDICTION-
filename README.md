# Installation 
```bash
git clone <https://github.com/gcolpari/STOCKMARKET_PREDICTION.git>
```

# Creation de un environment virtuelle 
On macOS
```bash
python -m venv venv
source venv/bin/activate
``` 
On Windows: 
```bash
python -m venv venv
venv\Scripts\activate
```
# Installer les dépendances
```bash
pip install -r requirements.txt
```
